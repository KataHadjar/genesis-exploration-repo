# Genesis exploration

Набор демонстрационных экспериментов с физическим движком [Genesis World](https://genesis-world.readthedocs.io/). Скрипты находятся в `scripts/`, готовые записи запусков — в `videos/`.

## Состав

| Скрипт | Что показывает | Запуск |
| --- | --- | --- |
| `scripts/materials_on_slope.py` | Движение тел с разными материалами по наклонной плоскости | `python scripts/materials_on_slope.py` |
| `scripts/mouse_control_with_cloth.py` | Интерактивное управление тканью мышью | `python scripts/mouse_control_with_cloth.py` |
| `scripts/two_robot_cloth_handover.py` | Передача и растяжение ткани двумя роботами | `python scripts/two_robot_cloth_handover.py` |
| `scripts/pick_water_cup_place_and_fall.py` | Робот Franka поднимает и наклоняет чашку с SPH-жидкостью, затем отпускает её | `python scripts/pick_water_cup_place_and_fall.py` |

## Эксперименты: описание и выводы

### Материалы на наклонной плоскости

Три одинаковых куба из условных стали, дерева и резины запускаются в отдельных дорожках на общей плоскости с наклоном 35°. Материалам заданы разные плотность, трение скольжения и трение качения; после заданного числа шагов скрипт печатает конечные координаты тел.

**Выводы.** Эксперимент показывает, как контактные параметры материала влияют на движение по наклонной поверхности. Раздельные дорожки позволяют сравнивать тела без столкновений друг с другом. Это качественная демонстрация: названия материалов условны, а количественное сравнение требует анализа координат или траекторий при фиксированных начальных условиях.

### Управление тканью мышью

Сцена содержит деформируемую ткань, кубы и плагин взаимодействия с мышью. Щелчок левой кнопкой выбирает ближайшую к лучу камеры частицу ткани в радиусе захвата; при движении мыши частица перемещается в плоскости перетаскивания. Флаг `--use_force` включает управление через скорость вместо прямого перемещения частицы, а `--num_envs` задаёт число параллельных сцен.

**Выводы.** Частицы ткани можно выбирать и перемещать напрямую из окна симуляции, что удобно для исследования деформации и реакции ткани на локальное воздействие. Режимы прямого перемещения и задания скорости позволяют сравнить резкое и более динамичное воздействие; устойчивость результата зависит от параметров ткани и симуляции.

### Передача и растяжение ткани двумя роботами

Два робота Franka захватывают жёсткие ручки, прикреплённые к краям ткани. Сначала один робот поднимает край, затем второй захватывает противоположную ручку; после этого роботы по очереди перемещают свои края, а затем совместно поднимают, растягивают и сжимают ткань.

**Выводы.** Сценарий демонстрирует координацию двух манипуляторов при взаимодействии с деформируемым объектом и передачу нагрузки через прикреплённые к ткани ручки. Изменение положений захватов приводит к подъёму и изменению формы ткани. Это демонстрационный сценарий заранее заданных траекторий, а не автономное планирование захвата или доказательство надёжности для произвольных условий.

### Перенос чашки и проливание SPH-жидкости

Franka захватывает чашку, наполненную частицами жидкости SPH, поднимает её, переносит в сторону и ставит на поверхность. Затем робот наклоняет чашку, чтобы жидкость вылилась, отпускает её и отводит манипулятор. Жидкость движется под действием своей модели, гравитации и контакта с коллизионными стенками чашки; визуальный OBJ-меш чашки не используется как физическая геометрия.

**Выводы.** Эксперимент объединяет управление манипулятором, контактный захват и двустороннее взаимодействие твёрдого тела с SPH-жидкостью. Последовательность показывает перенос и проливание жидкости при наклоне чашки. Это качественная демонстрация: скрипт проверяет факт подъёма чашки, но не измеряет объём пролитой жидкости и точность её размещения.

Записи результатов:

- `videos/materials_on_slope.mp4`
- `videos/mouse_control_with_cloth.mp4`
- `videos/two_robots_cloth_handover.mp4`
- `videos/pick_water_cup_place_and_fall.mp4`

Для визуализации чашки скрипт использует `scripts/water_cup.obj`. Этот OBJ-меш нужен только для отображения: физическая форма чашки задана в скрипте простыми коллизионными элементами.

## Окружение

Нужен Python **3.10–3.13**. Genesis требует PyTorch; подходящий вариант PyTorch зависит от ОС, GPU и версии CUDA/ROCm. Установите его по [официальной инструкции PyTorch](https://pytorch.org/get-started/locally/), затем установите проект и Genesis:

```bash
python3.12 -m venv .venv
source .venv/bin/activate        # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install torch      # Для GPU выберите команду с сайта PyTorch
python -m pip install -e .
```

В `pyproject.toml` указаны поддерживаемая версия Python и зависимость `genesis-world`. PyTorch устанавливается отдельно, чтобы выбрать сборку под конкретное оборудование. Для CPU запустите `materials_on_slope.py` как есть или используйте флаг `--cpu` у двух остальных сценариев. Скрипты с графическим окном требуют рабочего графического окружения; `materials_on_slope.py` также поддерживает `--headless`.

Проверьте интерпретатор и доступность основных библиотек:

```bash
python scripts/check_environment.py
```

## Запуск сценариев

Команды запускайте из корня репозитория. Основные параметры:

```bash
python scripts/materials_on_slope.py --headless --steps 300
python scripts/mouse_control_with_cloth.py --cpu
python scripts/two_robot_cloth_handover.py --cpu
python scripts/pick_water_cup_place_and_fall.py --cpu
```

В сценарии с чашкой также доступен флаг `--headless` для запуска без окна просмотра; он не меняет backend. Чтобы увидеть параметры конкретного сценария, добавьте `--help`. Сценарии с мышью, роботами и чашкой по умолчанию выбирают GPU; на системах без поддерживаемого GPU укажите `--cpu`.
